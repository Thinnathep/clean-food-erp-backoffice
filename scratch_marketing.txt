# 01 — Brand Guideline
## Clean Food CR

---

## 1. Brand Overview

**ธุรกิจ:** ร้านอาหารสุขภาพ สั่งล่วงหน้า ทำสดตามออเดอร์ จัดส่งเป็นรอบ ไม่มีหน้าร้าน
**ช่องทางขาย:** Facebook, LINE OA, TikTok (Website = ข้อมูลประกอบ ไม่ใช่ช่องทางขายหลัก)

**Brand Message (หลัก):**
> อาหารสุขภาพ วางแผนง่าย ส่งเป็นรอบ สดใหม่ทุกมื้อ

**Brand Message (รอง):**
> ไม่ต้องคิดเมนูเอง เราวางแผนให้ พร้อมจัดส่งตามรอบ

---

## 2. Brand Personality

| Trait | คำอธิบายเชิงดีไซน์ |
|---|---|
| สะอาด | White space เยอะ, ไม่รก, เส้นคมชัด |
| เป็นมิตร | โทนสีอบอุ่น, icon โค้งมน, ภาษาเข้าถึงง่าย |
| น่าเชื่อถือ | Layout เป็นระบบ, สัดส่วนสม่ำเสมอ, ไม่ใช้ effect ฉูดฉาด |
| ดูสุขภาพ | โทนเขียว-ธรรมชาติ, ภาพอาหารจริง แสงธรรมชาติ |
| ทันสมัย | Apple-style layout, rounded card, soft shadow |
| อบอุ่น | Accent ส้ม, โทนภาพนุ่มนวล ไม่เย็นชา |

**สิ่งที่แบรนด์ "ไม่ใช่":** ไม่ใช่ Fast Food (แม้ mood reference จะมาจาก KFC/McDonald's/Starbucks/MK แต่ต้องตีความใหม่ให้ Minimal / Premium / Healthy — ไม่ใช้สีสดจัดแบบฟาสต์ฟู้ด ไม่ใช้ layout อัดแน่น)

---

## 3. Target Customer (สำหรับอ้างอิงงานดีไซน์ทุกชิ้น)

**Primary:** คนรักสุขภาพ, คนทำงาน, ผู้สูงอายุ
**Secondary:** คนออกกำลังกาย

ผลลัพธ์เชิงดีไซน์: ตัวอักษรต้องอ่านง่าย (ขนาดไม่เล็กเกินไป เผื่อกลุ่มผู้สูงอายุ), contrast สูงพอสำหรับอ่านบนมือถือ, โทนภาษาเป็นกันเองไม่ใช้ศัพท์ฟิตเนสจ๋าเกินไป

---

## 4. Core Visual Language

- **Layout system:** Apple-style — white space กว้าง, grid สม่ำเสมอ, การจัดวางแบบ breathing room สูง
- **Shape language:** Rounded card, มุมโค้ง (radius กลาง-ใหญ่), ไม่ใช้มุมแหลม
- **Depth:** Soft shadow บางเบา + glass effect เล็กน้อยในบางองค์ประกอบ (ไม่ใช้ heavy drop shadow)
- **Icon:** Outline, Minimal, Rounded stroke
- **Photo style:** แสงธรรมชาติ, โทนอุ่น, อาหารจริงถ่ายสด ไม่ใช้ stock photo แบบ fast food

---

## 5. Do / Don't

**Do**
- ใช้ white space เป็นเครื่องมือสร้างความพรีเมียม
- ใช้สีเขียวเป็นสีหลักของทุกชิ้นงาน สีส้มเป็น accent เพื่อกระตุ้น action เท่านั้น
- ใช้ rounded card + soft shadow กับทุก content block

**Don't**
- ห้ามใช้สีสดจัดแบบฟาสต์ฟู้ด (แดง-เหลืองจัด)
- ห้ามอัด text/graphic แน่นเกินไปในพื้นที่เดียว
- ห้ามใช้ icon แบบ filled/หนา หรือ 3D

---

## 6. Priority ในการอ่านของลูกค้า (Visual Hierarchy หลักของแบรนด์)

1. Headline (ข้อความหลัก/โปรโมชั่น)
2. ภาพอาหาร
3. ราคา/จำนวนกล่อง
4. Subheadline
5. CTA Button
6. รายละเอียดย่อย (เงื่อนไข, พื้นที่จัดส่ง)

# 02 — Color System
## Clean Food CR

---

## 1. Palette

| Role | Hex | ชื่อ | การใช้งาน |
|---|---|---|---|
| Primary | `#6DBE45` | Healthy Green | พื้นหลัง header, ปุ่มหลัก, โลโก้, กราฟิกหลัก |
| Secondary | `#4A8F2B` | Dark Green | Text บนพื้นเขียวอ่อน, เส้นขอบ, hover state, gradient คู่กับ Primary |
| Accent | `#F6A623` | Warm Orange | CTA button, badge โปรโมชั่น, ราคา, จุดที่ต้องการให้สายตาหยุด |
| Background | `#F7F9F5` | Off-white Green Tint | พื้นหลังหลักของทุกงาน (แทนขาวล้วน เพื่อความอบอุ่น) |
| Text | `#222222` | Primary Text | Headline, body text หลัก |
| Secondary Text | `#666666` | Muted Text | Subheadline, caption, เงื่อนไขย่อย |
| Success | `#39B54A` | Success Green | สถานะสำเร็จ, checkmark, badge "จัดส่งแล้ว" |
| Error | `#E53935` | Error Red | แจ้งเตือน, badge "โควต้าเต็ม", สินค้าหมด |

---

## 2. สัดส่วนการใช้สี (60-30-10 Rule)

- **60% Background** — `#F7F9F5` เป็นพื้นหลักของทุก layout
- **30% Primary/Secondary Green** — กราฟิก, พื้นที่ header/footer, การ์ดโปรโมชั่น
- **10% Accent Orange** — เฉพาะจุด CTA, ราคา, badge — ห้ามใช้เกิน 10% ของพื้นที่ทั้งหมด เพื่อรักษาความพรีเมียม

---

## 3. Contrast & Accessibility

- Text `#222222` บน Background `#F7F9F5` → contrast สูง อ่านง่ายสำหรับกลุ่มผู้สูงอายุ
- ห้ามวาง Secondary Text `#666666` บนพื้น Primary Green โดยตรง (contrast ต่ำ) — ให้ใช้สีขาว (`#FFFFFF`) แทนเมื่ออยู่บนพื้นเขียว
- CTA Button ใช้ Accent Orange + ตัวอักษรสีขาว เท่านั้น (ห้ามใช้ text สีเข้มบนปุ่มส้ม)

---

## 4. Gradient (ใช้เฉพาะ Background/Section ใหญ่)

- Green Gradient: `#6DBE45 → #4A8F2B` ทิศทาง 135° ใช้กับ header banner เท่านั้น
- ห้ามทำ gradient บน text หรือปุ่ม CTA

---

## 5. การใช้สีตามองค์ประกอบ

| องค์ประกอบ | สีที่ใช้ |
|---|---|
| ปุ่ม CTA หลัก | Accent Orange + ตัวอักษรขาว |
| ปุ่มรอง/Outline | Primary Green border + text green, พื้นโปร่งใส |
| Badge ราคา/โปรโมชั่น | Accent Orange |
| การ์ดเมนู/โปรโมชั่น | Background ขาวอมเขียว + shadow เบา + ขอบ Primary Green บาง |
| Icon | Secondary Green (outline) |
| แจ้งเตือนผิดพลาด/หมดโควต้า | Error Red |
| แจ้งยืนยันสำเร็จ | Success Green |

# 03 — Typography
## Clean Food CR

---

## 1. Font Family

**ภาษาไทย:** Prompt (หลัก), Sarabun (body/เนื้อหายาว), Anuphan (รอง/ตัวเลือกสำรอง)
**ภาษาอังกฤษ:** Poppins

**หลักการเลือกใช้:**
- **Prompt** → Headline, ชื่อโปรโมชั่น, ราคา, ปุ่ม CTA (ตัวหนา สื่ออารมณ์ทันสมัย)
- **Sarabun** → เนื้อหาอธิบายยาว, เงื่อนไข, คำบรรยายเมนู (อ่านง่ายในระยะยาว เหมาะกับผู้สูงอายุ)
- **Anuphan** → ใช้เป็น alternative เมื่อ Prompt ไม่รองรับบางน้ำหนัก หรือใช้กับ UI ขนาดเล็ก (badge, label)
- **Poppins** → ตัวเลข, คำภาษาอังกฤษปน (เช่น "Clean Food CR"), ใช้คู่กับ Prompt ในบาง headline

---

## 2. Type Scale (สำหรับ Social Post / Poster)

| ระดับ | Font | Weight | ขนาด (Poster/Banner) | ขนาด (Social Square) | การใช้งาน |
|---|---|---|---|---|---|
| Display | Prompt | Bold/700 | 72–96px | 48–56px | Headline หลักของโปรโมชั่น |
| H1 | Prompt | SemiBold/600 | 48–56px | 32–36px | ชื่อโปร เช่น "ชุดสุขภาพสุดคุ้ม" |
| H2 | Prompt | Medium/500 | 32–36px | 24–28px | Subheadline |
| Price | Poppins | Bold/700 | 56–64px | 40–44px | ตัวเลขราคา (ใช้ Poppins เพราะตัวเลขคมชัดกว่า) |
| Body | Sarabun | Regular/400 | 20–24px | 16–18px | คำอธิบาย, เงื่อนไข |
| Caption | Sarabun | Regular/400 | 14–16px | 12–14px | หมายเหตุ, เงื่อนไขจัดส่ง |
| Button | Prompt | SemiBold/600 | 20–22px | 16–18px | ข้อความปุ่ม CTA |

---

## 3. Line Height & Letter Spacing

- Headline/Display: line-height 1.1–1.2, letter-spacing ปกติ (0)
- Body/Caption: line-height 1.5–1.6 (เพื่อการอ่านง่าย โดยเฉพาะกลุ่มผู้สูงอายุ)
- ปุ่ม/Label: letter-spacing +0.2px เพื่อความคมชัดในขนาดเล็ก

---

## 4. Hierarchy Rule ต่อ 1 ชิ้นงาน

1. **Headline** (ใหญ่ที่สุด, สีเข้ม `#222222` หรือขาวถ้าอยู่บนพื้นเขียว)
2. **ราคา/ตัวเลข** (Poppins Bold, สี Accent Orange)
3. **Subheadline** (Prompt Medium, สี Secondary Text `#666666`)
4. **Body/เงื่อนไข** (Sarabun Regular, เล็กสุด)

**ห้าม:** ใช้ font เกิน 2 ตระกูลในชิ้นงานเดียว (Prompt/Poppins คู่กันได้ แต่ห้ามผสม Sarabun+Anuphan+Prompt พร้อมกันในโพสต์เดียว)

# 04 — Design System
## Clean Food CR

---

## 1. Grid System

- **Social Post (1:1, 1080×1080):** Grid 12 column, gutter 24px, margin ขอบนอก 64px
- **Poster (A4/Portrait):** Grid 8 column, gutter 20px, margin ขอบนอก 80px
- **Banner (Wide/Facebook Cover):** Grid 12 column, gutter 24px, margin ขอบนอก 48px

---

## 2. Spacing Scale (8px Base Unit)

| Token | Value | การใช้งาน |
|---|---|---|
| xs | 8px | ระยะระหว่าง icon กับ text |
| sm | 16px | ระยะภายใน card เล็ก |
| md | 24px | ระยะระหว่าง element ในกลุ่มเดียวกัน |
| lg | 40px | ระยะระหว่างกลุ่มเนื้อหา (section gap) |
| xl | 64px | Margin ขอบนอกของ artwork |
| xxl | 96px | ระยะ breathing room รอบ headline หลัก (Apple-style) |

---

## 3. Padding & Margin มาตรฐาน

- **Card/Container padding:** 24–32px ทุกด้าน
- **Button padding:** แนวนอน 32px / แนวตั้ง 14px
- **Section margin (ระหว่างบล็อกเนื้อหา):** 40–64px
- **ขอบนอกสุดของภาพ (Safe Zone):** ห้ามวาง text/element สำคัญในระยะ 5% จากขอบภาพทุกด้าน

---

## 4. Rounded Card System

| องค์ประกอบ | Border Radius |
|---|---|
| Card ใหญ่ (โปรโมชั่น, เมนู) | 24px |
| Card เล็ก (badge, tag) | 12px |
| ปุ่ม CTA | 999px (pill shape) |
| รูปภาพในกรอบ | 20px |

---

## 5. Shadow System

- **Soft Shadow มาตรฐาน:** `0px 4px 16px rgba(34,34,34,0.08)` — ใช้กับ card ทุกใบ
- **Elevated Shadow (สำหรับปุ่ม CTA หรือ badge เด่น):** `0px 6px 20px rgba(246,166,35,0.25)` (ใช้เงาโทนส้มจาง เพื่อเน้น CTA)
- **ห้ามใช้:** เงาเข้ม/คมชัดแบบ hard shadow เพราะขัดกับความรู้สึก premium/minimal

---

## 6. Glass Effect (ใช้เฉพาะจุด)

- ใช้เฉพาะกับ badge ราคาที่วางทับภาพอาหาร หรือ tag บนรูปภาพ
- คุณสมบัติ: พื้นหลังขาวโปร่งแสง 70–80% + blur เบา + ขอบบางสีขาว 1px
- **ห้ามใช้ glass effect กับ text บล็อกใหญ่หรือปุ่ม CTA หลัก**

---

## 7. Icon System

- Style: Outline, Minimal, Rounded stroke (stroke width 1.5–2px)
- ขนาดมาตรฐาน: 24px (UI เล็ก), 40px (การ์ดโปรโมชั่น), 64px (Infographic/ไฮไลต์)
- สี: Secondary Green `#4A8F2B` เป็นหลัก, ใช้ Accent Orange เฉพาะ icon ที่ต้องการเน้น (เช่น badge "ส่งฟรี")

---

## 8. Component Library (แนวคิดหลัก — ไม่ใช่โค้ด)

| Component | ลักษณะ |
|---|---|
| Promotion Card | Rounded 24px, soft shadow, รูปอาหาร + badge ราคา + ชื่อโปร + ปุ่ม CTA |
| CTA Button | Pill shape, พื้น Accent Orange, text ขาว, elevated shadow |
| Price Badge | Glass effect, ตัวเลข Poppins Bold สีขาว/เขียวเข้ม |
| Info Tag (ส่งฟรี/แจ้งแพ้อาหารได้) | Rounded 12px, outline icon + text สั้น |
| Section Divider | เส้นบาง 1px สี Primary Green อ่อน 20% opacity + white space รอบข้าง |

# 05 — Promotion 299
## ชุดเริ่มต้นสุขภาพ

---

## 1. ข้อมูลจริงของโปร

- **ชื่อโปร:** ชุดเริ่มต้นสุขภาพ
- **ราคา:** 299 บาท
- **จำนวน:** 4 กล่อง
- **รูปแบบส่ง:** ครั้งเดียว
- **กลุ่มเป้าหมาย:** ลูกค้าใหม่, คนอยากลอง, ผู้สูงอายุ, คนทำงาน

---

## 2. Headline / Subheadline / CTA

- **Headline:** "ลองเริ่มต้นสุขภาพดี ในราคาที่ลองได้"
- **Subheadline:** "ชุดเริ่มต้นสุขภาพ 4 กล่อง 299 บาท ส่งครั้งเดียว ทำสดตามออเดอร์"
- **Button/CTA:** "เริ่มต้นเลย" หรือ "สั่งชุดเริ่มต้น"

*หมายเหตุ copy เพิ่มเติม → อ้างอิงไฟล์ 08_Promotion_Copywriting.md*

---

## 3. Layout (Social Post 1080×1080)

```
[ Safe Zone 5% ]
┌─────────────────────────────┐
│  Badge: "ลูกค้าใหม่"           │  ← top-left, glass effect
│                               │
│      [ ภาพอาหาร 4 กล่อง ]     │  ← กึ่งกลางบน, 55% ของพื้นที่
│                               │
│  Headline (Prompt Bold)      │
│  Subheadline (Prompt Medium) │
│                               │
│  [ 299 ] บาท   [ 4 กล่อง ]   │  ← Price badge, Poppins Bold
│                               │
│      ( ปุ่ม CTA pill )        │  ← Accent Orange
└─────────────────────────────┘
```

---

## 4. Spacing / Grid / Padding / Margin

- Grid: 12 column, gutter 24px
- Margin ขอบนอก: 64px
- Padding ภายใน content block: 32px
- ระยะห่างระหว่าง headline → subheadline: 16px
- ระยะห่างระหว่าง subheadline → price badge: 24px
- ระยะห่างระหว่าง price badge → ปุ่ม CTA: 40px

---

## 5. Typography

- Headline: Prompt Bold 48–56px, สี `#222222`
- Subheadline: Prompt Medium 24–28px, สี `#666666`
- ราคา: Poppins Bold 40–44px, สี Accent Orange `#F6A623`
- ปุ่ม CTA: Prompt SemiBold 18px, สีขาว

---

## 6. Icon

- Icon "ลูกค้าใหม่/ลองครั้งแรก" → outline icon รูป sparkle/star แบบ minimal เคียงกับ badge
- Icon กล่องอาหาร (4 กล่อง) → outline icon กล่องเรียงเป็นแถว ใช้แทนตัวเลขจำนวนกล่องในบาง layout

---

## 7. Photo Style

- ภาพอาหารสดใหม่ 4 กล่องจัดวางเป็นชุด แสงธรรมชาติโทนอุ่น
- มุมกล้อง 45° หรือ top-down เพื่อเห็นความหลากหลายของเมนู
- พื้นหลังภาพถ่าย: โต๊ะไม้อ่อน/ผ้าลินินสีครีม (ไม่ใช้พื้นหลังสีจัด)

---

## 8. Priority & Visual Hierarchy

1. ภาพอาหาร (ดึงดูดสายตาก่อน)
2. ราคา 299 + จำนวน 4 กล่อง (ตัวเลขต้องเด่นสุดรองจากภาพ)
3. Headline
4. ปุ่ม CTA
5. Badge "ลูกค้าใหม่"
6. Subheadline/เงื่อนไข

**เหตุผล:** โปรนี้เป็น entry point สำหรับลูกค้าใหม่ ต้องให้ตัวเลขราคาต่ำ + จำนวนกล่องเด่นชัด เพื่อลดความลังเลในการลองครั้งแรก

# 06 — Promotion 399
## ชุดสุขภาพคุ้มค่า

---

## 1. ข้อมูลจริงของโปร

- **ชื่อโปร:** ชุดสุขภาพคุ้มค่า
- **ราคา:** 399 บาท
- **จำนวน:** 5 กล่อง
- **รูปแบบส่ง:** ครั้งเดียว
- **กลุ่มเป้าหมาย:** คนดูแลสุขภาพ, ลูกค้าประจำ

# 08 — Promotion Copywriting
## Clean Food CR

*อ้างอิงข้อมูลจริงเท่านั้น: ธุรกิจสั่งล่วงหน้า ทำสดตามออเดอร์ ส่งเป็นรอบ ไม่มีหน้าร้าน / เมนูหมุนเวียนโดยร้าน ลูกค้าเลือกเมนูเองไม่ได้ / แจ้งแพ้อาหาร-ไม่เผ็ดได้ / ส่งฟรีในระยะ 5 กม. จากค่ายเม็งราย*

---

## 1. Headline หลักของแบรนด์ (ใช้ซ้ำได้ทุกช่องทาง)

- "อาหารสุขภาพ วางแผนง่าย ส่งเป็นรอบ สดใหม่ทุกมื้อ"
- "ไม่ต้องคิดเมนูเอง เราวางแผนให้ พร้อมจัดส่งตามรอบ"

---

## 2. Copy สำหรับโปร 299 (ชุดเริ่มต้นสุขภาพ)

**Headline options:**
- "ลองเริ่มต้นสุขภาพดี ในราคาที่ลองได้"
- "เริ่มต้นง่ายๆ กับมื้อสุขภาพ 4 กล่อง"

**Body copy:**
- "สำหรับคนอยากเริ่มดูแลสุขภาพ ไม่ต้องคิดเมนูเอง เราจัดให้ 4 กล่อง ส่งครั้งเดียว ทำสดตามออเดอร์"

**CTA:** "เริ่มต้นเลย" / "สั่งชุดเริ่มต้น"

---

## 3. Copy สำหรับโปร 399 (ชุดสุขภาพคุ้มค่า)

**Headline options:**
- "ดูแลสุขภาพต่อเนื่อง ในราคาคุ้มค่า"
- "5 กล่อง คุ้มกว่าเดิม สำหรับคนดูแลสุขภาพ"

**Body copy:**
- "สำหรับลูกค้าประจำและคนที่ดูแลสุขภาพอย่างต่อเนื่อง 5 กล่อง ส่งครั้งเดียว คุ้มค่ากว่าเดิม"

**CTA:** "สั่งชุดคุ้มค่า" / "ต่อยอดสุขภาพดี"

---

## 4. Copy สำหรับโปร 459 (ชุดสุขภาพสุดคุ้ม — โปรหลัก)

**Headline options:**
- "สุขภาพดีครบสัปดาห์ ในชุดเดียว"
- "6 กล่อง สุดคุ้ม โปรที่ลูกค้าเลือกมากที่สุด"

**Body copy:**
- "โปรโมชั่นหลักของร้าน 6 กล่อง ส่งครั้งเดียว คุ้มที่สุดในราคา 459 บาท"

**CTA:** "สั่งชุดสุดคุ้ม" / "เลือกโปรหลักของร้าน"

---

## 5. Copy สนับสนุน (ใช้แทรกในทุกโพสต์)

**เมนู:**
- "ร้านจัดเมนูหมุนเวียนให้ทุกมื้อ แจ้งแพ้อาหารหรือไม่เผ็ดได้"

**การจัดส่ง:**
- "ส่งฟรีในระยะ 5 กม. จากค่ายเม็งราย นอกพื้นที่คิดค่าส่งตามระยะทาง หรือเลือกส่งผ่าน Grab ได้"

**ความสดใหม่/กระบวนการ:**
- "สั่งล่วงหน้า ทำสดตามออเดอร์ ไม่มีของค้างสต๊อก"

---

## 6. Tone of Voice Guideline

- ใช้ภาษาที่เป็นกันเอง อบอุ่น ไม่ใช้ศัพท์ฟิตเนส/ลดน้ำหนักจ๋าเกินไป (เพราะกลุ่มเป้าหมายรวมผู้สูงอายุและคนทำงาน)
- ประโยคสั้น กระชับ อ่านจบในการมองครั้งเดียว (เหมาะกับ social scroll)
- หลีกเลี่ยงคำโปรยเกินจริง เช่น "ลดพุงใน 7 วัน" — เน้นความจริงของสินค้า (สดใหม่, วางแผนง่าย, ส่งตรงเวลา)

---

## 7. Priority การใช้ Copy ต่อ 1 โพสต์

1. Headline โปรนั้นๆ
2. ราคา/จำนวนกล่อง (ตัวเลขต้องอยู่ใกล้ headline)
3. CTA
4. Body copy สนับสนุน (เมนู/จัดส่ง)
5. Brand tagline หลัก (ใส่ท้ายโพสต์เป็น signature)

## 8. Priority & Visual Hierarchy

1. Headline (อ่านจากระยะไกลได้)
2. ภาพอาหาร
3. โปร 459 (เด่นกว่า 299/399 เพราะเป็นโปรหลัก)

# 13 — Banner Layout Design Spec
## Clean Food CR (Facebook Cover / Website Hero Banner)

*หมายเหตุ: Website เป็นเพียงข้อมูลประกอบ ไม่ใช่ช่องทางขายหลัก — banner นี้จึงเน้นสร้างความน่าเชื่อถือ (trust) มากกว่ากระตุ้นซื้อทันที*

---

## 1. ขนาดมาตรฐาน

- Facebook Cover: 1640×924px
- Website Hero: 1920×800px (wide)

---

## 2. Layout โครงสร้าง

```
[ Safe Zone 5% ]
┌───────────────────────────────────┐
│  Logo (left)         │  Headline    │
│                       │  Subheadline │
│   ภาพอาหาร Hero        │              │
│   (ขวา หรือเต็มพื้นหลัง  │  CTA เล็ก    │
│    แบบ overlay)        │              │
└───────────────────────────────────┘
```

- **โครงสร้างแบบ Split:** ซ้าย = ข้อความ (40%), ขวา = ภาพอาหาร (60%)
- ใช้ gradient green overlay บางๆ บนภาพ ฝั่งที่มีข้อความ เพื่อให้ text อ่านง่ายโดยไม่บังภาพ

---

## 3. Grid / Spacing / Padding / Margin

- Grid: 12 column, gutter 24px
- Margin ขอบนอก: 48–64px (wide banner ต้องเผื่อ margin มากกว่าปกติเพราะพื้นที่ crop ต่างกันในแต่ละแพลตฟอร์ม)
- Padding text block: 40px
- Safe zone สำหรับ Facebook Cover: เผื่อพื้นที่ 20% ด้านล่างสำหรับ profile picture overlap (ไม่วาง text สำคัญโซนนี้)

---

## 4. Typography

- Headline: Prompt Bold 40–48px (banner แนวนอน headline ไม่ควรใหญ่เกินเพราะพื้นที่แนวตั้งจำกัด)
- Subheadline: Prompt Medium 20–24px
- CTA text (ถ้ามี): Prompt SemiBold 16–18px

---

## 5. Icon

- Icon เล็กประกอบ trust signal เช่น "ทำสดตามออเดอร์" / "ส่งฟรีในเขตเมือง" วางเป็นแถวเล็กใต้ subheadline
- ขนาด icon 20px คู่กับ text 14–16px

---

## 6. Photo Style

- ภาพอาหาร wide-angle หรือ lifestyle (คนกำลังรับกล่องอาหาร) เพื่อสื่อความน่าเชื่อถือมากกว่าโปรโมชั่นเฉพาะราคา
- โทนแสงเดียวกับชุดภาพหลักของแบรนด์

---

## 7. Button / CTA

- Banner นี้เน้น brand awareness มากกว่าปิดการขาย → CTA เป็นทางเลือก ไม่บังคับต้องมี
- ถ้ามี ใช้ text link แบบ underline หรือปุ่ม outline (ไม่ใช้ปุ่ม solid Accent Orange เต็มแบบโปรโมชั่น เพราะ banner นี้ไม่ใช่จุดขายตรง)

---

## 8. Priority & Visual Hierarchy

1. ภาพอาหาร/lifestyle (สร้างความรู้สึกแบรนด์)
2. Headline (ข้อความแบรนด์หลัก ไม่ใช่ราคาโปร)
3. Subheadline
4. Trust signal icons
5. CTA (รอง)

**เหตุผล:** ต่างจาก Promotion Post ที่เน้นราคา/ปิดการขาย banner นี้ใช้จุดที่ลูกค้าเห็นแบรนด์ครั้งแรก (cover photo/เว็บไซต์) จึงเน้นสร้างความน่าเชื่อถือและตัวตนแบรนด์มากกว่า

# 15 — Design Checklist
## Clean Food CR — ใช้ตรวจสอบก่อนปล่อยงานทุกชิ้น

---

## 1. Brand Consistency

- [ ] ใช้สีจาก Color System เท่านั้น (`#6DBE45`, `#4A8F2B`, `#F6A623`, `#F7F9F5`, `#222222`, `#666666`)
- [ ] Accent Orange ไม่เกิน 10% ของพื้นที่ทั้งภาพ
- [ ] ฟอนต์ตรงตาม Typography spec (Prompt/Sarabun/Anuphan/Poppins เท่านั้น)
- [ ] ไม่ใช้ font เกิน 2 ตระกูลในชิ้นงานเดียว

---

## 2. Layout & Spacing

- [ ] เว้น Safe Zone 5% รอบขอบภาพ ไม่มี text/element สำคัญล้ำเข้าไป
- [ ] ใช้ spacing scale ตาม 8px base unit (8/16/24/40/64/96)
- [ ] Card ใช้ border radius ตามระบบ (24px ใหญ่ / 12px เล็ก / pill สำหรับปุ่ม)
- [ ] Shadow เป็น soft shadow เท่านั้น (ไม่มี hard shadow)

---

## 3. Content Accuracy (ข้อมูลต้องตรงกับธุรกิจจริง — ห้ามเดา)

- [ ] ราคาตรงกับโปรจริง (299/4 กล่อง, 399/5 กล่อง, 459/6 กล่อง)
- [ ] ระบุ "ส่งครั้งเดียว" ถูกต้องในทุกโปร (ไม่ใช่ subscription รายวัน)
- [ ] เงื่อนไขส่งฟรีถูกต้อง (ไม่เกิน 5 กม. จากค่ายเม็งราย)
- [ ] ระบุถูกต้องว่าลูกค้าเลือกเมนูเองไม่ได้ (ร้านจัดเมนูหมุนเวียนให้) แต่แจ้งแพ้อาหาร/ไม่เผ็ดได้
- [ ] ไม่มีข้อความที่สื่อว่ามีหน้าร้าน (ธุรกิจไม่มีหน้าร้าน)

---

## 4. Typography Hierarchy

- [ ] Headline เด่นที่สุดรองจากภาพอาหาร
- [ ] ราคาใช้ Poppins Bold สี Accent Orange เสมอ
- [ ] ขนาดตัวอักษร body/เงื่อนไขไม่เล็กกว่า 16px (เผื่อกลุ่มผู้สูงอายุอ่านง่าย)

---

## 5. Photo Style

- [ ] แสงธรรมชาติ โทนอุ่น ไม่ใช้แสงเย็น/จัดจ้านแบบฟาสต์ฟู้ด
- [ ] ภาพอาหารเป็นภาพจริงของร้าน ไม่ใช่ stock photo ทั่วไป
- [ ] มุมกล้อง top-down หรือ 45° ตามมาตรฐาน

---

## 6. CTA & Icon

- [ ] ปุ่ม CTA เป็น pill shape สี Accent Orange ตัวอักษรขาว

## 7. Visual Hierarchy ต่อชิ้นงาน (เรียงลำดับสายตาถูกต้องหรือไม่)

# 16 — Campaign Guideline
## Clean Food CR

*ไฟล์นี้อยู่เหนือระดับชิ้นงานเดี่ยว (05–13) — ใช้ควบคุมว่าเมื่อโปรโมชั่นทั้ง 3 (299/399/459) และช่องทางทั้ง 3 (Facebook/LINE OA/TikTok) ทำงานร่วมกันในแต่ละสัปดาห์ ต้องออกมาเป็นชุดเดียวกัน ไม่ใช่คนละทิศทาง*

---

## 1. โครงสร้างแคมเปญรายสัปดาห์ (Weekly Cadence)

เนื่องจากธุรกิจสั่งล่วงหน้า ตัดรอบ 21:00 และส่งรอบ 11:00–13:00 ทุกวัน แคมเปญจึงวิ่งเป็นรอบ **รายวัน (เมนูหมุนเวียน) ซ้อนทับกับรายสัปดาห์ (โปรโมชั่น 3 ระดับ)**

| วัน | คอนเทนต์หลัก | โปรที่ดัน |
|---|---|---|
| จันทร์–อังคาร | เปิดสัปดาห์ / เมนูหมุนเวียนใหม่ | โปร 459 (หลัก) |
| พุธ–พฤหัส | Social proof / lifestyle / ลูกค้าประจำ | โปร 399 |
| ศุกร์–เสาร์ | กระตุ้นลูกค้าใหม่ก่อนวันหยุด | โปร 299 |
| อาทิตย์ | สรุปสัปดาห์ / เตรียมออเดอร์สัปดาห์ถัดไป | โปร 459 |

*หมายเหตุ: จำนวนคอนเทนต์ต่อวันต้องสอดคล้องกับกำลังผลิตสูงสุด 20 กล่อง/วัน — ห้ามออกแบบแคมเปญที่กระตุ้นออเดอร์เกินกำลังผลิต*

---

## 2. Message Arc ต่อโปรโมชั่น (ไม่ให้ 3 โปรแย่งความสนใจกันเอง)

- **299 = จุดเริ่มต้น** → โทน copy: ชวนลอง, ความเสี่ยงต่ำ
- **399 = ความต่อเนื่อง** → โทน copy: คุ้มค่าระยะยาว, สำหรับคนที่ลองแล้ว
- **459 = จุดปิดการขายหลัก** → โทน copy: คุ้มที่สุด, ตัวเลือกที่คนส่วนใหญ่เลือก (social proof)

**กฎ:** ห้ามชู 2 โปรพร้อมกันในโพสต์เดียวด้วยน้ำหนักภาพเท่ากัน — ต้องมีโปรหลัก 1 โปรต่อโพสต์เสมอ (ตามหลัก Visual Hierarchy ในไฟล์ 04)

---

## 3. Cross-Channel Consistency

| องค์ประกอบ | ต้องเหมือนกันทุกช่องทาง | ปรับได้ตามช่องทาง |
|---|---|---|
| สี, ฟอนต์, โลโก้, Icon style | ✅ ต้องเหมือนกัน 100% | — |
| ภาพอาหาร (Hero shot ต่อโปร) | ✅ ใช้ภาพชุดเดียวกัน | ครอปสัดส่วนต่างกันได้ |
| ขนาด Headline/Layout | — | ✅ ปรับตามพื้นที่จอ (LINE เล็กกว่า FB) |
| Copy/CTA | โครง Message Arc เดียวกัน | ✅ ปรับความยาวตามแพลตฟอร์ม (LINE สั้นสุด) |

---

## 4. Layout / Spacing / Grid (ระดับแคมเปญ — Layout ภาพรวมของชุดโพสต์ต่อสัปดาห์)

- ใช้ Grid และ Spacing scale เดียวกับไฟล์ 04_Design_System.md ทุกชิ้นงานในแคมเปญ (ห้ามมีชิ้นงานใดใช้ grid ต่างระบบ)
- ระยะห่างระหว่างโพสต์ในชุด carousel (ถ้ามี): ใช้ template เดียวกัน สลับแค่ hero image/ราคา (ตามแนวคิด modular ในไฟล์ 12)

---

## 5. Typography / Icon / Photo Style (ระดับแคมเปญ)

- Typography และ Icon ใช้ระบบเดียวกับไฟล์ 03/04 ทุกชิ้นงาน ไม่มีข้อยกเว้นระดับแคมเปญ
- Photo Style: ภาพ Hero ต่อโปร (299/399/459) ต้องใช้ชุดเดียวกันตลอดทั้งเดือน เพื่อสร้างการจดจำ ไม่ถ่ายใหม่ทุกสัปดาห์ (ประหยัดเวลาโปรดักชันสำหรับทีมคนเดียว)

---

## 6. Button / CTA ระดับแคมเปญ

- CTA ของโปรหลักประจำสัปดาห์ ต้องใช้ข้อความเดียวกันตลอดสัปดาห์ (ไม่สลับ CTA copy รายวัน) เพื่อสร้างความจำ
- CTA ของโปรรอง (299/399 ในสัปดาห์ที่ไม่ใช่โปรหลัก) ใช้ tone รองตาม Message Arc ข้อ 2

---

## 7. Priority & Visual Hierarchy ระดับแคมเปญ

1. โปรหลักประจำสัปดาห์ (ตาม cadence ข้อ 1)
2. ความสม่ำเสมอของภาพ/สี/ฟอนต์ข้ามช่องทาง
3. Message Arc ของแต่ละโปร (ไม่ให้ทับซ้อนกันเอง)
4. กำลังผลิตสูงสุด 20 กล่อง/วัน (เพดานที่ห้ามแคมเปญกระตุ้นเกิน)

---

## 8. เชื่อมกับภาพใหญ่ (Big Picture)

Campaign Guideline นี้คือ **Phase 1** ของการ systemize การตลาด Clean Food CR — เมื่อรันจนคงที่ (เนื้อหา/cadence ซ้ำได้โดยไม่ต้องคิดใหม่ทุกสัปดาห์) จะกลายเป็น template ที่ต่อยอดเป็นส่วนหนึ่งของ Vertical SaaS (ระบบการตลาดสำเร็จรูปสำหรับธุรกิจสุขภาพรายอื่น ภายใต้ Kuro Neko Digital ในระยะถัดไป)

# 17 — Design Tokens
## Clean Food CR

*ไฟล์นี้คือ "แหล่งข้อมูลจริงเดียว" (Single Source of Truth) ของค่าตัวเลขดีไซน์ทั้งหมด — ใช้ค่าจากไฟล์นี้เท่านั้นไม่ว่าจะทำงานบน Canva, Figma, หรือ Web/Code เพื่อให้หน้าตาออกมาเหมือนกันทุกแพลตฟอร์ม*

## 7. ใช้งานจริงในแต่ละแพลตฟอร์ม

**Canva:** ตั้งค่า Brand Kit → ใส่ค่าสีตาม token, ฟอนต์ตาม token, ระยะ padding/margin ใช้ grid guide คูณด้วยค่า spacing (เช่น margin ขอบนอก = XL = 64px)

**Figma:** สร้าง Variables/Styles ชื่อ token ตรงกับตารางนี้เป๊ะ (เช่น `spacing/M`, `radius/pill`, `color/accent`) เพื่อให้เปลี่ยนค่าที่เดียวแล้วอัปเดตทุกไฟล์

**Web/Code:** แปลงเป็น CSS Variables ตรงตัว —

```css
:root {
  --spacing-xs: 8px;
  --spacing-s: 16px;
  --spacing-m: 24px;
  --spacing-l: 40px;
  --spacing-xl: 64px;
  --spacing-xxl: 96px;

  --radius-s: 12px;
  --radius-m: 24px;
  --radius-l: 40px;
  --radius-pill: 999px;

  --button-height: 56px;
  --card-padding: 32px;
  --icon-size: 24px;

  --shadow-card: 0 8px 24px rgba(0,0,0,.08);
  --shadow-cta: 0 6px 20px rgba(246,166,35,.25);

  --color-primary: #6DBE45;
  --color-secondary: #4A8F2B;
  --color-accent: #F6A623;
  --color-background: #F7F9F5;
  --color-text: #222222;
  --color-text-secondary: #666666;
  --color-success: #39B54A;
  --color-error: #E53935;
}
```

---

## 8. กฎการใช้ Token (ห้ามฝ่าฝืน)

- ห้ามใส่ค่าตัวเลข spacing/radius/shadow แบบ "เดาเอง" นอกตารางนี้ในทุกชิ้นงาน
- หากต้องการค่าตัวใหม่ (เช่น radius 20px สำหรับ container พิเศษ) ต้องเพิ่มเป็น token ใหม่ในไฟล์นี้ก่อน แล้วค่อยใช้งาน — ไม่ผสมค่าที่ไม่มีอยู่ใน token list ลงในงานจริง
- ไฟล์ 04, 05–13, 16 ทั้งหมดต้องอ้างอิงค่าเดียวกับตารางนี้เสมอ (ถ้าไฟล์ไหนมีค่าเลขไม่ตรงกับที่นี่ ให้แก้ไฟล์นั้นให้ตรง ไม่ใช่แก้ตารางนี้)
