# 06 — Promotion 399
## ชุดสุขภาพคุ้มค่า

---

## 1. ข้อมูลจริงของโปร

- **ชื่อโปร:** ชุดสุขภาพคุ้มค่า
- **ราคา:** 399 บาท
- **จำนวน:** 6 กล่อง
- **รูปแบบส่ง:** ครั้งเดียว
- **กลุ่มเป้าหมาย:** คนดูแลสุขภาพ, ลูกค้าประจำ

---

## 2. Headline / Subheadline / CTA

- **Headline:** "ดูแลสุขภาพต่อเนื่อง ในราคาคุ้มค่า"
- **Subheadline:** "ชุดสุขภาพคุ้มค่า 6 กล่อง 399 บาท ส่งครั้งเดียว เหมาะสำหรับลูกค้าประจำ"
- **Button/CTA:** "สั่งชุดคุ้มค่า" หรือ "ต่อยอดสุขภาพดี"

---

## 3. Layout (Social Post 1080×1080)

```
[ Safe Zone 5% ]
┌─────────────────────────────┐
│  Badge: "คุ้มค่า / ลูกค้าประจำ" │
│                               │
│      [ ภาพอาหาร 6 กล่อง ]     │  ← จัดเรียงแบบ grid 2 แถว เห็นความหลากหลาย
│                               │
│  Headline (Prompt Bold)      │
│  Subheadline (Prompt Medium) │
│                               │
│  [ 399 ] บาท   [ 6 กล่อง ]   │
│                               │
│      ( ปุ่ม CTA pill )        │
└─────────────────────────────┘
```

---

## 4. Spacing / Grid / Padding / Margin

- Grid: 12 column, gutter 24px, margin ขอบนอก 64px
- Padding content block: 32px
- Headline → Subheadline: 16px
- Subheadline → Price badge: 24px
- Price badge → CTA: 40px
- *(เหมือน template 299 เพื่อความสม่ำเสมอของชุดโปรโมชั่น — ต่างกันที่เนื้อหาตัวเลข/ภาพ)*

---

## 5. Typography

- Headline: Prompt Bold 48–56px, สี `#222222`
- Subheadline: Prompt Medium 24–28px, สี `#666666`
- ราคา: Poppins Bold 40–44px, สี Accent Orange `#F6A623`
- ปุ่ม CTA: Prompt SemiBold 18px, สีขาว

---

## 6. Icon

- Icon "คุ้มค่า" → outline icon รูปโล่/ริบบิ้นเล็ก (แทนความหมาย "คุ้มค่ากว่า")
- Icon กล่องอาหาร 6 กล่อง → ใช้ชุดเดียวกับโปร 299 แต่เพิ่มจำนวน

---

## 7. Photo Style

- ภาพอาหาร 7 กล่อง จัดวางแบบ overhead grid เห็นความหลากหลายเมนูชัดเจนกว่าโปร 299
- แสงธรรมชาติ โทนอุ่น เหมือนชุดโปร 299 เพื่อความต่อเนื่องของแบรนด์

---

## 8. Priority & Visual Hierarchy

1. ภาพอาหาร (จำนวนกล่องมากกว่าโปร 299 → ให้ความรู้สึก "คุ้มกว่า")
2. ราคา 399 + จำนวน 6 กล่อง
3. Badge "คุ้มค่า/ลูกค้าประจำ" (เน้นมากกว่าโปร 299 เพราะกลุ่มเป้าหมายเป็นลูกค้าที่ตัดสินใจจาก value)
4. Headline
5. ปุ่ม CTA
6. Subheadline

**เหตุผล:** กลุ่มเป้าหมายเป็นคนดูแลสุขภาพ/ลูกค้าประจำ → เน้น "ความคุ้มค่า" มากกว่าความใหม่ ต่างจากโปร 299 ที่เน้นการลองครั้งแรก
