# 07 — Promotion 459
## ชุดสุขภาพสุดคุ้ม (โปรโมชั่นหลักของร้าน)

---

## 1. ข้อมูลจริงของโปร

- **ชื่อโปร:** ชุดสุขภาพสุดคุ้ม
- **ราคา:** 459 บาท
- **จำนวน:** 6 กล่อง
- **รูปแบบส่ง:** ครั้งเดียว
- **สถานะ:** ⭐ โปรโมชั่นหลักของร้าน (Hero Promotion)

---

## 2. Headline / Subheadline / CTA

- **Headline:** "สุขภาพดีครบสัปดาห์ ในชุดเดียว"
- **Subheadline:** "ชุดสุขภาพสุดคุ้ม 7 กล่อง 459 บาท ส่งครั้งเดียว คุ้มที่สุดของร้าน"
- **Button/CTA:** "สั่งชุดสุดคุ้ม" หรือ "เลือกโปรหลักของร้าน"

---

## 3. Layout (Social Post 1080×1080) — ต้องเด่นกว่าโปรอื่นเพราะเป็น Hero

```
[ Safe Zone 5% ]
┌─────────────────────────────┐
│  Badge เด่น: "โปรแนะนำของร้าน" │  ← ใหญ่กว่า badge โปรอื่น ใช้ Accent Orange เต็ม
│                               │
│    [ ภาพอาหาร 7 กล่อง ]       │  ← ครอบคลุม 60% พื้นที่ (ใหญ่ที่สุดในชุดโปรทั้งหมด)
│                               │
│  Headline (Prompt Bold ใหญ่) │
│  Subheadline (Prompt Medium) │
│                               │
│  [ 459 ] บาท   [ 7 กล่อง ]   │  ← ตัวเลขใหญ่กว่าโปรอื่น
│                               │
│      ( ปุ่ม CTA pill ใหญ่ )    │
└─────────────────────────────┘
```

---

## 4. Spacing / Grid / Padding / Margin

- Grid: 12 column, gutter 24px, margin ขอบนอก 64px (เท่าเทมเพลตอื่นเพื่อความสม่ำเสมอ)
- Padding content block: 32–40px (มากกว่าโปรอื่นเล็กน้อยเพื่อความรู้สึก "premium/hero")
- Headline → Subheadline: 16px
- Subheadline → Price badge: 24px
- Price badge → CTA: 40px
- Badge เด่น "โปรแนะนำของร้าน" วางเหนือ headline ระยะห่าง 20px

---

## 5. Typography

- Headline: Prompt Bold 56–64px (ใหญ่กว่าโปร 299/399 10–15%), สี `#222222`
- Subheadline: Prompt Medium 24–28px, สี `#666666`
- ราคา: Poppins Bold 48–56px (ใหญ่ที่สุดในชุดโปรโมชั่น), สี Accent Orange `#F6A623`
- ปุ่ม CTA: Prompt SemiBold 20–22px, สีขาว

---

## 6. Icon

- Icon "โปรแนะนำ/สุดคุ้ม" → outline icon รูปดาว/มงกุฎเล็ก แบบ minimal (สื่อว่าเป็นตัวเลือกอันดับ 1)
- Icon กล่องอาหาร 7 กล่อง → ชุดเดียวกับโปรอื่น เพิ่มจำนวน

---

## 7. Photo Style

- ภาพอาหาร 7 กล่อง จัดวางเต็มพื้นที่มากกว่าโปรอื่น เพื่อสื่อความ "ครบ คุ้ม เต็มอิ่ม"
- แสงธรรมชาติโทนอุ่นเดียวกับชุดโปร 299/399 (คงความต่อเนื่องของ series)
- อาจเพิ่มมุมภาพ lifestyle (คนทำงาน/ครอบครัวกำลังรับกล่องอาหาร) เพื่อสื่อว่าเป็น "โปรหลักที่คนส่วนใหญ่เลือก"

---

## 8. Priority & Visual Hierarchy

1. Badge "โปรแนะนำของร้าน" (ต้องเห็นก่อนสุดเพื่อดึงความสนใจว่านี่คือตัวเลือกหลัก)
2. ภาพอาหาร 7 กล่อง
3. ราคา 459 + จำนวน 7 กล่อง (ใหญ่ที่สุดในชุดโปรทั้งหมด)
4. Headline
5. ปุ่ม CTA (ใหญ่กว่าโปรอื่นเล็กน้อย)
6. Subheadline

**เหตุผล:** เนื่องจากเป็นโปรโมชั่นหลักของร้าน ทุก element ต้อง "ใหญ่กว่าเล็กน้อย" เมื่อเทียบกับโปร 299/399 เพื่อสร้าง visual anchor ให้ลูกค้าเปรียบเทียบแล้วรู้สึกว่านี่คือตัวเลือกที่คุ้มที่สุด (decoy/anchor effect ในเชิงดีไซน์)
