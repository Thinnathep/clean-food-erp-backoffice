# 11 — Poster Layout Design Spec
## Clean Food CR

*ใช้สำหรับ: โปสเตอร์ประกอบการตลาด (แจกจุดส่ง/ป้ายประกอบ) — ไม่ใช่ช่องทางขายหลัก แต่ต้องคงมาตรฐานแบรนด์เดียวกัน*

---

## 1. ขนาดมาตรฐาน

- A4 Portrait (2480×3508px @300dpi) — ใช้หลัก
- A3 สำหรับจุดที่ต้องการความเด่นมากขึ้น (สัดส่วนเดียวกัน x2)

---

## 2. Layout โครงสร้าง

```
[ Safe Zone 5% ]
┌─────────────────────────┐
│  Logo (top-center)        │
│                           │
│  Headline ใหญ่             │  ← จุดสนใจแรก ต้องอ่านได้จากระยะไกล
│                           │
│    ภาพอาหาร Hero          │  ← 40% ของพื้นที่ กึ่งกลาง
│                           │
│  โปรโมชั่น 3 รายการ         │  ← จัดเรียงแนวนอน/แนวตั้ง เท่ากัน 3 ช่อง
│  (299 / 399 / 459)        │     459 เด่นกว่าเล็กน้อย (ตรงกลาง/ใหญ่กว่า)
│                           │
│  Footer: ช่องทางติดต่อ      │  ← LINE OA, Facebook, เวลาสั่ง/ส่ง
└─────────────────────────┘
```

---

## 3. Grid / Spacing / Padding / Margin

- Grid: 8 column, gutter 20px
- Margin ขอบนอก: 80px (A4)
- Padding ระหว่าง section (Headline/ภาพ/โปรโมชั่น/Footer): 48–64px
- Padding ภายในแต่ละ card โปรโมชั่น: 24px
- ระยะห่างระหว่าง card โปรโมชั่นทั้ง 3: 20px เท่ากัน

---

## 4. Typography

- Headline: Prompt Bold 96–120px (ใหญ่ที่สุดในชุด design pack เพราะต้องอ่านได้จากระยะไกล)
- ชื่อโปรแต่ละรายการ: Prompt SemiBold 36–40px
- ราคา: Poppins Bold 56–64px
- Footer text: Sarabun Regular 24–28px

---

## 5. Icon

- Icon จัดส่ง (มอเตอร์ไซค์) + Icon เวลา → วางคู่กับ footer เพื่อสื่อรอบส่ง 11:00–13:00
- Icon LINE/Facebook → วางคู่ footer ช่องทางติดต่อ

---

## 6. Photo Style

- ภาพอาหาร Hero เดียวกับชุด Facebook/LINE เพื่อความสม่ำเสมอ
- ต้องเป็นภาพความละเอียดสูง (300dpi) เนื่องจากพิมพ์จริง

---

## 7. Button / CTA

- โปสเตอร์ไม่มีปุ่มกดจริง แต่ต้องมี "CTA เชิงข้อความ" ชัดเจน เช่น "สั่งผ่าน LINE OA @282ovoyd" พร้อม QR Code
- QR Code วางมุมล่างขวา ขนาดไม่ต่ำกว่า 3×3 ซม. เพื่อสแกนง่าย

---

## 8. Priority & Visual Hierarchy

1. Headline (อ่านจากระยะไกลได้)
2. ภาพอาหาร
3. โปร 459 (เด่นกว่า 299/399 เพราะเป็นโปรหลัก)
4. โปร 299 / 399
5. Footer + QR Code (ช่องทางสั่งซื้อ)

**หมายเหตุ:** เนื่องจากโปสเตอร์เป็นสื่อ "ข้อมูลประกอบ" ไม่ใช่ช่องทางขายหลัก จึงเน้นสร้างการจดจำแบรนด์ + นำทางกลับไปที่ LINE OA เป็นเป้าหมายหลักของ CTA
