# README — Clean Food CR Business Foundation (Sprint 1)

## นี่คืออะไร

ชุดเอกสาร Business Foundation ที่สร้างจาก `CleanFoodCR_Starter_Pack.zip` โดยใช้**เฉพาะข้อมูลจริง**ที่มีในไฟล์ต้นฉบับ (ส่วนใหญ่มาจาก `00_AI_CONTEXT.md`) ส่วนที่ไม่มีข้อมูลถูกทำเครื่องหมาย TODO ไว้ทั้งหมด — ไม่มีการเดาหรือสร้างข้อมูลใหม่

## โครงสร้างไฟล์ทั้งหมด

| ลำดับ | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| 1 | `01_Company_Profile.md` | ข้อมูลพื้นฐานบริษัท |
| 2 | `02_Mission_Vision.md` | พันธกิจ/วิสัยทัศน์ |
| 3 | `03_Business_Model.md` | โมเดลธุรกิจ |
| 4 | `04_SWOT.md` | จุดแข็ง/จุดอ่อน/โอกาส/ความเสี่ยง |
| 5 | `05_Target_Customers.md` | กลุ่มลูกค้าเป้าหมาย (มี conflict สำคัญ) |

## ลำดับการอ่านที่แนะนำ

1. `BUSINESS_AUDIT_REPORT.md` — ดูภาพรวมสถานะก่อน
2. `14_Project_Summary.md` — สรุปย่อทั้งโครงการ
3. `12_Open_Questions.md` — ดู conflict/คำถามที่ต้องตอบก่อน
4. ไฟล์ 01–13 ตามลำดับหมายเลข — รายละเอียดแต่ละหัวข้อ
5. `15_Next_Action.md` — สิ่งที่ต้องทำต่อ

## สำหรับ AI ตัวอื่น (ChatGPT / Antigravity)

**เริ่มอ่านจาก `10_AI_MEMORY.md` ก่อนเสมอ** — เป็นไฟล์เดียวที่สรุป Verified Facts แบบ structured (YAML) พร้อม flag ข้อมูลที่ยังไม่ verified และ conflict ที่ยังไม่คลี่คลาย ห้ามเดาหรือเติมข้อมูลแทนส่วนที่เป็น TODO

## ข้อจำกัดสำคัญของชุดนี้

จากไฟล์ต้นฉบับ 19 ไฟล์ มีเพียง `00_AI_CONTEXT.md` ที่มีข้อมูลจริง — ไฟล์อื่นเป็น scaffolding เปล่า ดังนั้นเอกสารชุดนี้จึงมี TODO จำนวนมาก ตามกฎ "ห้ามเดา" ที่กำหนดไว้ตั้งแต่ต้น เมื่อ GG เติมข้อมูลจริงในไฟล์ต้นฉบับแล้ว แนะนำให้รัน Sprint 1 ซ้ำเพื่ออัปเดตชุดเอกสารนี้
