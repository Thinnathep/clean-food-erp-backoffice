# AI Mistake Logger

## จุดประสงค์

Skill นี้ใช้สำหรับ:
1. **บันทึกข้อผิดพลาด** ที่ AI ทำไปในไฟล์ `mistake-log.md`
2. **อ่านข้อผิดพลาดเก่า** ก่อนเริ่มทำงาน เพื่อไม่ทำซ้ำ
3. **เตือนตัวเอง** ให้ระวังเป็นพิเศษในจุดที่เคยพลาด

---

## เมื่อไหร่ต้องใช้ Skill นี้

- เมื่อ user บอกว่า AI ทำอะไรผิด หรือตำหนิการทำงาน
- เมื่อ AI ตรวจพบว่าตัวเองทำพลาด เช่น ลบสิ่งที่ไม่ควรลบ แก้ผิด scope ฯลฯ
- เมื่อเริ่ม task ใหม่ที่ซับซ้อน — **อ่าน mistake-log.md ก่อนเสมอ**

---

## วิธีใช้งาน

### ขั้นตอนที่ 1: อ่าน mistake-log.md ก่อนทำงาน

ทุกครั้งที่เริ่ม task ที่เกี่ยวกับโค้ดหรือการแก้ไขไฟล์ ให้อ่านไฟล์:

```
d:\VS CODE\Project CR\.agents\skills\ai-mistake-logger\mistake-log.md
```

ใช้ข้อมูลในไฟล์นั้นเพื่อ:
- หลีกเลี่ยงรูปแบบผิดพลาดที่เคยเกิด
- ตรวจสอบจุดที่ต้องระวังเป็นพิเศษก่อน execute

### ขั้นตอนที่ 2: บันทึกข้อผิดพลาดใหม่

เมื่อเกิดข้อผิดพลาด ให้เพิ่มบันทึกใน `mistake-log.md` ตาม format ด้านล่าง:

```markdown
## [วันที่] — [ชื่อย่อของข้อผิดพลาด]

**สิ่งที่ผิดพลาด:**
[อธิบายสั้น ๆ ว่าทำอะไรผิดพลาด]

**สาเหตุ:**
[ทำไมถึงผิด — เข้าใจผิด? scope เกิน? ไม่ตรวจสอบก่อน?]

**ผลกระทบ:**
[สิ่งที่หาย/พัง เพราะข้อผิดพลาดนี้]

**วิธีแก้ไขที่ถูกต้อง:**
[ควรทำอย่างไร]

**กฎที่ต้องจำ:**
> ⚠️ [ประโยคสั้น ๆ เตือนตัวเอง]
```

---

## กฎพื้นฐานที่ต้องจำ (อ่านทุกครั้ง)

อ่านไฟล์ `mistake-log.md` เพื่อดู checklist ที่อัปเดตอยู่เสมอ

กฎถาวรที่ไม่มีวันเปลี่ยน:
1. **ห้ามลบส่วนที่ไม่ได้รับคำสั่งให้ลบ** — หาก user ขอแก้ A อย่าแตะ B
2. **ตรวจสอบ scope ของ request ก่อน execute** — เข้าใจให้ชัดว่า "อะไร" ที่ต้องแก้
3. **อย่าเขียนทับ block ขนาดใหญ่** หาก patch จุดเดียวพอ ใช้ targeted edit เสมอ
4. **อ่าน diff ก่อน commit** — ตรวจสอบว่ามีอะไรหลุดออกไปโดยไม่ตั้งใจไหม

---

## Format สรุปท้าย task

หลังแก้ไขข้อผิดพลาดแล้ว ให้รายงาน user ในรูปแบบนี้:

```
🔴 ข้อผิดพลาดที่เกิดขึ้น: [สรุป 1 บรรทัด]
✅ แก้ไขแล้วโดย: [สรุปวิธีแก้]
📝 บันทึกแล้วใน mistake-log.md เพื่อไม่ทำซ้ำ
```
