# AI Self-Updating & Continuous Learning Guide

> **วัตถุประสงค์**: เพื่อให้ AI ERP ตัวนี้สามารถ "อัปเดตตัวเอง" เมื่อมีความรู้ใหม่ มีการเปลี่ยนแปลง Schema หรือแก้ไขจุดผิดพลาดในโปรเจกต์ Clean Food CR

---

## 1. Trigger Conditions สำหรับการอัปเดตตัวเอง

AI ต้องตรวจสอบและอัปเดตไฟล์ Reference ในสกิลนี้เมื่อ:
1. **มีการเปลี่ยนแปลงหรือเพิ่มตารางใน Database (`SQL_database.sql` หรือ Supabase Migration)**: ให้อัปเดตตารางและ Foreign Keys ใน `references/schema_guide.md`
2. **มีการปรับปรุงกฎธุรกิจ (Business Constitution)** เช่น ราคา, โปรโมชั่น, รอบจัดส่ง: ให้อัปเดต `SKILL.md` และ `references/domain_logic.md`
3. **เกิดข้อผิดพลาดในการเขียนโค้ด หรือ User แจ้งแก้ไข**: ให้บันทึกรูปแบบข้อผิดพลาดและวิธีแก้ไขที่ถูกต้องลงใน `mistake-log.md`
4. **มีการเพิ่ม Library หรือ Component ใหม่ในโปรเจกต์**: ให้อัปเดตรายการ Technology Stack ใน `SKILL.md`

---

## 2. ขั้นตอนการอัปเดตตัวเอง (Self-Update Protocol)

1. **ตรวจสอบความถูกต้อง (Verify First)**: ตรวจสอบโค้ดหรือไฟล์ฐานข้อมูลจริงก่อนทำการเขียน
2. **บันทึกลง Reference ที่เกี่ยวข้อง**: เพิ่มหรือแก้ไขเนื้อหาในโฟลเดอร์ `references/`
3. **อัปเดตสรุปใน `SKILL.md`**: ปรับแต่ง Metadata หรือหัวข้อหลักหากมีการเปลี่ยนแปลงโครงสร้างใหญ่
4. **แจ้งให้ User ทราบ**: รายงานสิ่งที่ได้เรียนรู้และอัปเดตลงในสกิลอย่างชัดเจน
